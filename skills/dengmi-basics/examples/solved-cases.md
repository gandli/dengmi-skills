# 实战复盘案例 (Worked Cases)

三类典型案例：形路单字、形路多字地名、义路地名。

---

## 案例一：形路·单字谜 — "十一点进厂"

**谜面**：十一点进厂
**谜目**：打一字
**谜底**：压

**复盘**：
1. **缩圈**：谜目"打一字"→单字谜，候选即常见独体/合体字数十个
2. **判路**："进厂"=入+进厂→形路（增补法）；"十一点"非时间，拆为十+一+丶
3. **分段**：单段"十一点/进厂"
4. **拆解**：十+一+丶（三笔）合置于厂字框内→压
5. **回查**：无闲字（十/一/点/进/厂全有用），底面不相犯（压≠面中字）
6. **验证**：压=厂+土，十+一=土，丶补其上（的点）——句读为"十、一、点，进厂"✓

## 案例二：形路·多字地名谜 — "进厂生产，干到两点没下岗"

**谜面**：进厂生产，干到两点没下岗
**谜目**：福州市长乐区地理名称
**谜底**：六平山

**复盘**：
1. **缩圈**：长乐区著名山川名胜—六平山、首石山、猴屿洞天岩、五峰山……十余个候选
2. **判路**：出现"进/到/没/下"→形路，增补+减损为主
3. **分段**：三段语义事件（进厂生产/干到两点/没下岗）→假设三字地名
4. **拆解**：
   - 段1「进厂生产」→ 六：属经典字谜固定扣法（昼夜生产字谜库中"下厂就生产=六"为成例）
   - 段2「干到两点」→ 平：增补法，干中插两点(丷)→平
   - 段3「没下岗」→ 山：减损法，岗去下部"冈"，保留"山"
5. **回查**：三戒通过；进厂生产/干到两点/没下岗一字不落
6. **验证**：六平山（又名鹿屏山）位于长乐区吴航街道东北，海拔564.6米，为长乐主山，有东溪精舍及摩崖石刻群——方志与官网可查（clnews.com.cn / fzcl.gov.cn），实存

**可复用经验**：
- 遇地名谜，先建候选池（辖内镇/乡/街/村/自然村/名胜），再拆字
- "进/到/没/下"是形路高信号词
- 一段扣一字是最常见多字扣法，段数≈字数

## 案例三：义路·地名谜 — "全民炼钢"

**谜面**：全民炼钢
**谜目**：湖北地名
**谜底**：大冶

**复盘**：
1. **缩圈**：湖北地名（县市）→几十个候选
2. **判路**：无拆字操作词，"炼钢"是动作事件→义路（会意/借代）
3. **拆解**：全民=大（全体/大伙）；炼钢=冶（冶炼）→大冶
4. **回查**：底面不相犯，无闲字，"冶"扣"炼"（冶炼）
5. **验证**：大冶为湖北省黄石市代管县级市，实存

**可复用经验**：
- 无操作词、句子通顺→优先试会意；"全民"类词→大/众；"炼/制"→冶/造
- 义路谜往往一个词扣一字，一句话扣多字

## 案例四：形路·长句增损 — "千里草，十日卜"（离合+拆字）

**谜面**：千里草，十日卜
**谜目**：打一字
**谜底**：董、卓（两个字，用"同旁字"或增损法）

**复盘**（简要）：
- 千里（两个"千"字部件）+草（艹）→ 董（艹+重，重=千里草合）
- 十日（十+日=早）+卜→ 卓（早+卜）
- 此为离合+增损复合，注意两段各自完整
