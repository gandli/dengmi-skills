## 四、谜目惯例速查

- **地名谜**：按行政层级/自然地貌/名胜分类；实存优先（方志、标准地名库、政府网）
- **人名谜**：注意历史人物朝代、生卒、字号、别称；用典须核实典源
- **成语谜**：多为别解+谐音；注意成语有固定四字/多字结构
- **物名谜（动物/植物/食物/器物）**：会意+象形双路；动物看叫声/习性，植物看形/季节
- **字谜**：单字谜多用形路；注意一字谜不能与谜面有相同字
- **诗句/古文句**：出处须能对上；运典法要能说出典源

## 五、谜格速查（详见 SKILL.md）

无格优先；有格时先套格再解义。卷帘/秋千（倒读）、掉首/掉尾/双钩（移位）、徐妃（去同偏旁）、骊珠（谜目+谜底合猜）。

## 六、常见"射虎"（多解）雷区

- "一加一"型面 → 王/田/土 都可能，需谜目限定
- "半"字谜 → 需谜目（字/词）
- 只有"会意"而无"字形操作"能扣的面 → 慎用形路猜法，反之亦然

## 六、常见扣合套路（盲测实战补充）

### 1. 方位嵌套规则（X里 / X外 / X中 / X边）
| 谜面 | 扣法 | 例 |
|---|---|---|
| 田**里**禾苗 | 部件装进 田 框内 | 囗 + 禾 |
| 田**外**草青 | 部件放到框外（多在顶部） | 艹 置于外 |
| 山**下**月 | 取字下半 | 峰 = 山+夆下半 |
| 厂**内**有一横 | 部件入 厂 内 | 压 = 厂+土+丶 |
合："田里苗绿田外草青" → 艹(外草) + 囗(田) + 禾(里苗) = **菌**

### 2. 动作词 → 操作映射
| 谜面词 | 实际操作 |
|---|---|
| 改革 / 重新调配 / 改组 | 部件拆散重排 |
| 盖草 / 戴帽 | 加 艹 / 加 亠 / 加 冖 |
| 前夕 | 取前字去尾（"六一"前夕 → 衙 = 行+吾，"吾"末笔前） |
| 选段 / 上下集 / 各半 | 半面法 |
| 留一手 | 保留 扌 或 保留 一 |
| 一致力 | 一 + 致 + 力 合成（致去?= 功） |
| 十无四五 | 十 去掉 四/五 的笔画 |

### 3. 唯一性检查（防多解，必做）
联网搜谜面原句。若出现 **两个以上都讲得通的底**，该谜为"多解"（射虎不中），
不可强判唯一；正确做法是报告多解并列出各自成立路径。
实例："有位佳人在水一方" → **汝**（佳人=女+氵）与 **洳**（佳人=如+氵）双解并存。

### 4. 判错信号的实测教训
- 只读谜面猜"意思"（如"田里苗绿"→苗）而未走**形路拆装** → 必错（正确 菌）
- 忽略"改革/重排"这类**重排指令** → 必错（"一旦改革大有作为" → 春，旦+大 重排）
- 答案与谜面某字同形但**来源不同**（如把"草"直接取艹而不看"外"）→ 漏方位约束
