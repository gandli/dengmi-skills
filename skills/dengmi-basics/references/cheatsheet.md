## 二、借代词库（替代法/运典法）

### 天干地支 ↔ 生肖
子鼠｜丑牛｜寅虎｜卯兔｜辰龙｜巳蛇｜午马｜未羊｜申猴｜酉鸡｜戌狗｜亥猪

### 方位 ↔ 五行
东木｜南火｜西金｜北水｜中土
（如"东木"→东面属木/青/春；"南火"→南方、午、丙丁）

### 天干
甲乙丙丁戊己庚辛壬癸

### 日月别称
日：金乌、太阳、阳、精、火（东方）
月：玉兔、望舒、蟾、阴、兔（西方）

### 颜色
青/蓝/碧 → 东/春/木
朱/赤/丹/红 → 南/火
白/皓/素 → 西/金
黑/玄/缁 → 北/水
黄/黄土 → 中/土

### 常见扣法示例
- "东边下雨西边晴"（成语式谜面）→ 分歧（东/西分岔）——先看形再看义
- "白" = 西方/金/秋
- "半" = 的一半 / 各半 / 半面

## 四、谜目惯例速查

- **地名谜**：按行政层级/自然地貌/名胜分类；实存优先（方志、标准地名库、政府网）
- **人名谜**：注意历史人物朝代、生卒、字号、别称；用典须核实典源
- **成语谜**：多为别解+谐音；注意成语有固定四字/多字结构
- **物名谜（动物/植物/食物/器物）**：会意+象形双路；动物看叫声/习性，植物看形/季节
- **字谜**：单字谜多用形路；注意一字谜不能与谜面有相同字
- **诗句/古文句**：出处须能对上；运典法要能说出典源

## 五、谜格速查（详见 SKILL.md）

无格优先；有格时先套格再解义。卷帘/秋千（倒读）、掉首/掉尾/双钩（移位）、徐妃（去同偏旁）、骊珠（谜目+谜底合猜）。

## 六、常见"射虎"（多解）雷区

- "一加一"型面 → 王/田/土 都可能，需谜目限定
- "半"字谜 → 需谜目（字/词）
- 只有"会意"而无"字形操作"能扣的面 → 慎用形路猜法，反之亦然
