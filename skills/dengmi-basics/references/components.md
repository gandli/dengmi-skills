# 部件字典（形路谜的真正基础设施）

正向从谜面猜字必然失败——**必须逆向枚举**：先枚举候选部件的组合，再回查谜面逐词扣合。
本表提供「谜面词 ↔ 部件」的映射，是逆向枚举的检索底座。

## 一、穴/宀/冖类（覆盖、空、盖）
| 谜面词 | 部件 |
|---|---|
| 抽空、天空、空虚 | 穴 |
| 房、屋、家、宫 | 宀 |
| 盖、覆、蒙、盖头 | 冖 |
| 宝盖 | 宀 |

## 二、弓/长/矢类（张、弯、射）
| 谜面词 | 部件 |
|---|---|
| 张（去长）| 弓 |
| 弯、钩、别解"张" | 弓 |
| 长、长久 | 长 / 𠂉 |

## 三、象形部件（最常被忽略的一类）
| 谜面词 | 部件 |
|---|---|
| 一弯残月、残月、钩月、新月 | 乚 |
| 点、滴、雨点、星 | 丶 |
| 细浪、微波、浪花（三点） | 氵 或 丶丶丶（视位） |
| 山、峰、岳 | 山 |
| 眉月、弯月 | ⺈ |
| 人字、八字、分开 | 八 / 人 |
| 耳、听 | 耳 |
| 舟、扁舟、航 | 舟 |

## 四、增损高频操作部件
| 操作 | 部件效果 |
|---|---|
| 抽去 X | 减去含 X 的部件（如 张−长=弓） |
| 添一"点" | ＋丶 |
| 盖草、加草 | ＋艹 |
| 添口 | ＋口 |
| 去心 | 忄/心 相减（如 恒−忄=亘） |

## 五、逆向枚举 SOP（形路字谜标准动作）
1. **切词**：把谜面切成 3-5 个词，每个词映射到 1-2 个候选部件（查本表）。
2. **枚举组合**：把候选部件按常用合体字两两/三三组合，生成候选字（优先查表一/表三的现成合体）。
3. **回查**：对每个候选字，逐词写"部件 → 谜面词"的对应句。写得出来才保留。
4. **留空字检查**：若某词无法安顿 → 该候选作废（谜无闲字）。
5. **多解裁决**：若两个候选都成立，联网搜原句对比谁更"工整"（部件数与词数更齐整者胜）。

### 示范（"一叶飞来细浪生"）
- 切词：一叶飞来 / 细浪 / 生
- 部件：一叶飞来 → 乚（叶形如钩落地）；细浪 → 丶丶丶；生 → 生成/产出（动词，非部件）
- 组合：乚 + 丶丶丶 = **心** ✓（卧钩 + 三点）
- 回查：乚←一叶飞来，丶丶丶←细浪，"生"作动词"生出"✓ 无闲字
- 结论：心。（误答"性"的教训：只抓"忄+生"是语感，不是拆字）

### 反面示范（"张省长抽空下基层"）
- 切词：张 / 省长 / 抽空 / 下基层
- 部件：张→弓+长；抽空→穴；下基层→土
- 组合：穴 + 弓 = **穹** ✓（"长"被"省"掉 = 减损法）
- 结论：穹。（误答"涨"= 只想到"张"加氵，漏掉减损与"抽空"）
