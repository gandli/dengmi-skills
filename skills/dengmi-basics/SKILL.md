# 灯谜通解 (Lantern Riddles: Universal Knowledge & Solving Method)

适用于任意谜目（字、词、成语、地名、人名、物品、诗句、影视……）的通用知识与解法。
细节查表见 `references/cheatsheet.md`，实战案例见 `examples/solved-cases.md`。

## 一、三要素与三戒

**三要素**：谜面（破谜条件）＋谜目（答案范围）＋谜底（答案）。谜目标注谜格时另加"格法"约束。

**三戒（判定合格谜底的红线）**：
1. **底面不相犯**：谜底用字不得在谜面出现。
2. **谜面无闲字**：谜面每个字都须有交代（作部件、作操作词、作方位词或会意成分），一字不落空。
3. **谜底须别解**：别解是谜趣之源——底、面任一侧按非常义解读；若按本义直解便索然，多半是路走错了。

## 二、六步解谜法（通用流程）

```
1 缩圈 Bounding     榨干谜目：枚举候选池，锁定答案类别/字数/领域，无限空间 → 小候选集
2 判路 Route triage 扫描谜面信号词，分流：形路（拆字）/ 义路（会意用典）/ 音路（谐音借代）
3 分段 Segmentation 按标点、语意事件断句；多字谜底常"一段扣一字"，段数≈字数可作假设
4 拆解 Deduction    逐段执行：取部件、按操作词增删、方位截取、重组；或会意/用典/借代
5 回查 Loop-back    用三戒自检：闲字？相犯？每段解释唯一且无歧义？对不上就换路，不硬凑
6 验证 Verification 实证谜底真实性（地名/人名/物产须实存）；谜目吻合、可倒验（底释面通顺）
```

**关键纪律**：
- 检索先行——先搜谜面原句与变体，找现成底；找不到则回到第一性推理，不臆造成语/地名。
- 每步缩小假设空间；任何一步出现两个以上同样自洽的候选，回到谜目重新缩圈。
- 拆解失败三次 → 怀疑判路错误（把义路谜当形路谜是最常见错误）。

## 三、判路信号表（速查）

| 路线 | 谜面指纹 | 首选谜法 |
|---|---|---|
| **形路** | 操作词密集：进/入/到/加/没/去/下/残/半/头/尾/东西南北 | 离合、增补、减损、方位、半面 |
| **义路** | 句子通顺无操作词；引典故、诗句、成语；描述特征 | 会意、问答、运典、借代、排除 |
| **音路** | 谜目提示"谐音/梨花格"，或语义明显不通而音通 | 梨花格、替代（同音假借） |

高频操作词最小集（完整表见 cheatsheet）：
- **增**：进、入、到、来、加、添、带、含、有
- **删**：没、无、去、除、掉、落、残、缺、忘、休、莫
- **位**：头、尾、中、心、边、上、下、左、右、东、西、南、北（上北下南左西右东）
- **合**：合、并、聚、共、同、和、伴、陪、连
- **分**：分、拆、离、别、断、各、判

## 四、十五种制谜/解谜法（通用一句话版）

1. **会意**：以面释底，正扣或反扣（"全民炼钢"→大冶）。
2. **象形**：按笔画轮廓取形（"残月三星"→心）。
3. **离合**：拆字再组装（"孔雀东南飞"→孙）。
4. **别解**：曲解词性/语义（"干"由"干活"→干字；"两点"由钟点→笔画）。
5. **半面**：各取一字之半合成（"多出一半"→岁）。
6. **方位**：按上下左右/部位取字素（"村边"→木或寸）。
7. **增补**：加笔画/部件（"干到两点"→平）。
8. **减损**：去笔画/部件（"岗"去"冈"→山）。
9. **排除**：言非所以定是（"一加一不是二"→王）。
10. **抵消**：面内自相抵剩者成底（"大扫除"类）。
11. **问答**：设问自答成谜。
12. **运典**：文史典故扣合（用典先核典实）。
13. **夹击**：序列中取被夹之物（"人地生疏"→单晓天：天地人夹"天…地"间取"晓天"义，例有异说，用前先验）。
14. **换算**：数量/单位/进制互换（"十二元"→打百分：一打=12、一元=100分）。
15. **替代（借代）**：同义/固定借代词库：地支↔生肖、方位↔五行、日月别称、姓氏郡望等（详见 cheatsheet）。

**组合使用**：实战常"一句多法"——先分段，段内各选主法，最后合体校验。

### 多段并列谜面（成语/词语谜高频，占语料 11%，必先判别）
谜面含 `；` 分隔成多段时，**各段不是并列描述，而是"多条独立线索同时指向同一底"**。

**实测确认的主模式：段 → 成语的半字（2 字单元）**
每段独立扣成语的**一半**，两段拼出四字成语。判别动作：逐段独立解出 2 字 → 拼接成 4 字。

| 谜面 | 分段扣合 | 底 |
|---|---|---|
| 神似；抽象画 | 神似→得意；抽象画→忘形 | **得意忘形** |
| 阎王殿；潜水艇 | 阎王殿→无常；潜水艇→出没 | **出没无常** |
| 剧团下乡；巡回演出 | 巡回→逢场；剧团下乡→作戏 | **逢场作戏** |
| 钴——钤；故事新编 | 钴—钤=古；故事新编=今用 | **古为今用** |
| 四舍值；管它是多少 | 四舍=不计；管多少=其数 | **不计其数** |

**次模式：共享去部**（各段含同一部件、去掉后成谜）
傲；你；僖；位（都去亻）→ 旁若无人

**失败模式（实测两轮）**：
1. 把多段当"一句长句"整体会意 → 必然失败（`沉鱼落雁` 之于 `阎王殿；潜水艇`）
2. 只抓到一段就急着填成语 → 半字模式要求**两段都扣住**才算成立
3. 段序与成语序**不保证一致**，拼接后须回查调序（如 `剧团下乡；巡回演出` 拼作 `逢场作戏`）

### 形路标准动作：逆向枚举（字谜专用，必做）
正向"读谜面猜字"成功率极低——必须先**逆向**：切词 → 候选部件枚举 → 组合 → 回查。
详细步骤、示范、反面示范与部件映射表见 `references/components.md` 第五/六节。
没有部件字典，形路字谜几乎必然失败（离线基线 5%）。

## 五、七大常见谜格（格法一句话）

| 格 | 规则 |
|---|---|
| 卷帘格 | 底≥3字，倒读扣面（"岛"→地中海：海中地） |
| 秋千格 | 底恰2字，倒读扣面 |
| 掉首格 | 底≥3字，前2字互换后读 |
| 掉尾格 | 底≥3字，末2字互换后读 |
| 双钩格 | 底4字，前后2字对调 |
| 徐妃格 | 底各字同偏旁，删偏旁后扣面（"_easy_"类，须底字共偏旁） |
| 骊珠格 | 不标谜目，谜目+谜底一起猜（"刀枪入库"→将军·马歇尔） |

无格为主流；见格先套格再拆义，格不违三戒。

## 六、通用验证清单（收尾必查）

- [ ] 谜底严格落在谜目范围内（类别/字数/地域限定）
- [ ] 三戒：无闲字、无相犯、有别解
- [ ] 每一段都有明确谜法解释，无一段依赖"感觉像"
- [ ] 底为实存对象：地名查政府/方志/标准地名库，人名查典籍，物名查通名
- [ ] 倒验：以底逐字反推谜面，逐词通顺、无需额外假设
- [ ] 唯一性：候选池中无第二解同样自洽（多解=谜病"射虎不中"风险，注明存疑）
