# 灯谜基础知识与解谜工作流 (Lantern Riddle Fundamentals & Solving Workflow)

## 一、谜语基本结构与“三戒”

灯谜由三要素组成：**谜面、谜目、谜底**，缺一不可。

- **谜面**：破谜条件与思考依据，多为短诗、韵文、成语或通俗短语。
- **谜目**：答案限定范围（如“打一字”、“猜长乐区地理名称”）。答非所目即错。
- **谜底**：终极答案，须与谜面严密扣合。

### 灯谜三戒
1. **底面不相犯（面底不相撞）**：谜底中字绝不能在谜面出现（特例如某些特殊复字谜除外）。
2. **谜无闲字**：谜面每个字词在解谜时都应有安顿（或为部件、或为操作词、或为方位词），不应有多余无意义字。
3. **字必别解**：字不作原义解释，通过形、音、义的转折产生谜趣。

## 二、六步解谜工作流（六步法）

面对新谜时，依序执行以下六步：

```
[1. 缩圈 (Bounding)]
    ↓ 依靠谜目压紧候选域（如特定地名、特定类别、字数约束）
[2. 判路 (Route Triage)]
    ↓ 识别“形路”（字形离合增损）还是“义路”（会意/用典/借代）
[3. 分段 (Segmentation)]
    ↓ 根据标点、语意断句与字数对应，划分各字段落
[4. 拆解/会意 (Deduction)]
    ↓ 提取部件字、执行操作词指令（加、减、拼、转）或意合提取
[5. 回查 (Loop-back)]
    ↓ 检查谜面是否“无闲字”，各字扣合是否吻合谜法与语法
[6. 验证 (Verification)]
    ↓ 核验候选谜底真实性、权威性（地名/典故/实体是否真实存在）
```

## 三、解谜路径判定与操作词特征

### 1. 形路（字形离合增损）特征
谜面常含**动作词、空间词、加减词**，提示对汉字笔画部件进行物理操作：

| 操作类别 | 常见操作词（触发词） | 操作示例 |
|---|---|---|
| **增补/进位** | 进、入、到、来、装、纳、带、添、补、共 | “干到两点” → 干+丷 = 平 |
| **减损/残缺** | 没、去、除、掉、别、残、丢、缺、断、半 | “没下岗” → 岗-冈 = 山 |
| **方位/截取** | 上、下、左、右、前、后、头、尾、中、边、心 | “下厂” → 取厂部；“西出阳关” → 扣方位 |
| **离合/拼组** | 合、分、连、交、并、聚、结、牵、凑 | “二季度进厂” → 厂内加两季部件 |

### 2. 义路（会意/运典/替代）特征
谜面通顺连贯，多为诗句、成语、情景描述，无拆字动词，注重词义转折与借代。

## 四、十五种经典制谜/解谜法

1. **会意法**：以面释底，意合神会。例：“人面不知何处去” → 丢脸。
2. **象形法**：抓取字形视觉轮廓。例：以“丫丫”为底，面出“两个三叉路口”。
3. **离合法**：拆开部件再依意重组。例：“又进村来” → 树（村拆为木、寸，加“又”）。
4. **别解法**：违背原义借字生义。例：“言而无信”解作“传话而无信件”。
5. **半面法**：单取字的上半、下半、左半或右半。
6. **方位法**：依东/南/西/北/前/后/内/外截取字素。
7. **增补法**：原字追加偏旁或笔画。例：“想发财，要聚才” → 贝。
8. **减损法**：原字剔除特定笔画部首。例：“仗” → 一落千丈（丈落一笔）。
9. **排除法**：指明排除某种可能反求其余。例：“一加一不等于二” → 王。
10. **抵消法**：面与底或同句字素相互抵冲。
11. **问答法**：以设问与应答成谜。例：“怎么开口？” → 全凭嘴一张。
12. **运典法**：借用文史、戏曲、历史人物典故扣合。
13. **夹击法**：在固定词组序列中取首尾夹中间。例：“人地生疏” → 单晓天（天地人三才）。
14. **换算法**：借数量、重量、进制互为换算。例：“十二元” → 打百分（一打=12，一元=100分）。
15. **替代法**：天干地支、五行方位、别名借代。例：“袭人之子” → 花生（花袭人=花，之子=生）。

## 五、七大经典谜格

1. **卷帘格**：底不少于三字，倒读释面。例：“岛” → 地中海（海中地）。
2. **秋千格**：底限二字，倒读扣面。
3. **掉首格**：底不少于三字，前两字互换位置。
4. **掉尾格**：底不少于三字，末两字互换位置。
5. **双钩格**：底限四字，前二字与后二字对调位置。
6. **徐妃格**：底字共具同一偏旁，皆削去该偏旁扣面。
7. **骊珠格（探骊格）**：面不标谜目，须自行探出谜目与谜底合读。

## 六、实战全流程范例（复盘案例）

- **谜面**：进厂生产，干到两点没下岗
- **谜目**：福州市长乐区地理名称
- **全流程复盘**：
  1. **缩圈**：长乐区核心自然与人文地名集中在吴航街道主山与江海名胜（六平山、首石山、猴屿等）。
  2. **判路**：出现“进、到、没、下”，判定为“字形增损离合谜”。
  3. **分段**：三短语对应三字地名（进厂生产 / 干到两点 / 没下岗）。
  4. **拆字推理**：
     - 第一段「进厂生产」：增损法。厂中纳“生”合成“产”（或昼夜生产字谜标准扣法“六”）。
     - 第二段「干到两点」：增补法。“干”字追加两点“丷”，合成“平”字。
     - 第三段「没下岗」：减损法。“岗”字去掉下部“冈”，保留顶部“山”字。
  5. **组合回查**：得「六平山」。
  6. **地理实证**：六平山（又称鹿屏山）坐落于福州市长乐区吴航街道东北，山高564.6米，为长乐主山，留存东溪精舍与宋明摩崖石刻群。六字无闲字，完全符合灯谜规范。
