# 灯谜 Agent Skills (Dengmi Skills)

Chinese lantern riddle (灯谜) agent skills collection.

## Skills

- **dengmi-basics** — 灯谜基础知识与解谜工作流：谜语三要素（谜面/谜目/谜底）、灯谜三戒（底面相犯/闲字/无别解）、六步解谜法（缩圈→判路→分段→拆字→回查→验证）、形路/义路判定与操作词表、经典谜格（卷帘格/秋千格/掉首格/掉尾格/双钩格/徐妃格/骊珠格）、15种制谜方法（会意/象形/离合/别解/半面/方位/增补/减损/排除/抵消/问答/运典/夹击/换算/替代）、实战复盘案例（"进厂生产，干到两点没下岗" → 六平山）

## Install

```bash
npx skills add gandli/dengmi-skills
```
